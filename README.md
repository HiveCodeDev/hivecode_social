# hivecode_social

Imagens e planos das publicações do Instagram da HiveCode (@hivec0de).
Os ficheiros em `posts/` são servidos pelo GitHub Pages para o Instagram os poder descarregar.

- `tools/render.mjs`, `tools/render_one.mjs`: geram as imagens a partir de HTML com o Edge local.
- `tools/publish.mjs`: publica um post aprovado de um ficheiro em `plans/` (lê o token das variáveis de ambiente; nunca o guarda).
